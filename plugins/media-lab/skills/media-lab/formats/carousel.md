# Carousel (Instagram, LinkedIn document)

| Slide | Job |
|---|---|
| 1 | Promise. Big headline, max ~8 words, plus a visual cue that there is more (arrow, "1/7"). |
| 2 | Second hook. The feed may re-show the post starting here, so it must also stand alone. |
| 3 to n-1 | One idea per slide. Same layout every slide; headline + 1-3 short lines or one visual. |
| mid | Soft CTA ("save this for later") somewhere around the middle. |
| last | Clear CTA tied to the goal metric: save, send to a friend who..., comment a specific answer, follow for part 2. |

Design rules:
- Same size for every slide (4:5 default). Margins at least 80 px.
- Large type: headline 64-90 px, body 36-44 px at 1080 width.
- One accent colour; numbers and key words in the accent.
- Put the handle or a small logo in the same corner on every slide.
- Export PNG for Instagram, a single PDF for LinkedIn.

Build: see `recipes/carousel.md` (HTML/CSS to PNG/PDF, or Pillow).
