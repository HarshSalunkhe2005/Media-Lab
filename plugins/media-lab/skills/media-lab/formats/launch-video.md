# Launch / promo video (product, app, project)

Length: 20-45 s vertical for social, 60-90 s 16:9 for a README or landing page.

| Beat | Time (30 s cut) | Content |
|---|---|---|
| Hook | 0-3 s | the result or the "wow" screen first, with a 4-6 word headline |
| Problem | 3-8 s | one line of the pain, shown not told |
| Demo | 8-22 s | 3 fast moments of the product doing the thing; zoom into the cursor/UI; captions name each step |
| Proof | 22-26 s | a number, a quote (real, with permission), or a before/after |
| CTA | 26-30 s | name + where to get it, on screen long enough to read |

Tips:
- Record UI at 2x resolution, then crop/zoom in the edit; static full-screen UI is unreadable on phones.
- Use the product's real colours and type in the titles.
- Music with a clear beat; cut on the beat.
- If the `brag` / `brag-slim` skill is installed, it can auto-build a launch video from a repo or URL. Use this file to brief it and to review its output.
- Tools: Remotion for animated UI mockups and kinetic type; ffmpeg for screen-recording edits (`recipes/`).
