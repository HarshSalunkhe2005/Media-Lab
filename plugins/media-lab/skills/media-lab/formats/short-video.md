# Short vertical video (Shorts, Reels, TikTok)

## Structures that work (pick one per piece)

| Structure | Beats | Good for |
|---|---|---|
| Problem → twist → fix | hook names a pain, show the wrong way, reveal the right way | tips, dev tricks |
| Countdown list | "3 ..." then 3, 2, 1, best last | tools, facts (the countdown itself holds attention) |
| Before → after | show result first, rewind to how | builds, edits, transformations |
| Myth bust | state the common belief, prove it wrong on screen | science, finance, tech |
| Story in 30 s | situation, tension, turn, punchline | faceless story channels, event recaps |
| Build log | "I built X in N hours", 3 milestones, demo | dev/builder accounts, launches |
| Event recap | best moment first, 4-6 fast highlights, result card | sports, fests |

## Production checklist
- Hook spoken + on screen in 2 s; strongest shot first.
- Visual change every 2-4 s.
- Word-level captions, 1-3 words per block, current word highlighted, inside safe zone.
- Loud enough, music ducked under voice.
- Ending loops to the start or asks one specific question.
- Description: one line restating the promise, 1-3 specific hashtags.
- Synthetic/AI visuals or voice: set the platform's disclosure flag.
