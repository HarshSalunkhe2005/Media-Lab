# Hook library

Hooks are patterns, not lines to paste. Fill them with the real specifics of your piece; a generic fill is worse than no hook.
Examples use fictional names.

## Opening hooks (first 2 seconds)

| Pattern | Shape | Example (fictional) |
|---|---|---|
| Result first | "[specific result] in [short time/with constraint]" | "This app found 212 duplicate photos in 9 seconds." |
| Unfinished number | "[N] [things], and the last one [surprise]" | "4 ffmpeg flags I use daily. The last one saved a whole edit." |
| Contrarian | "[common belief] is wrong. Here's what [proof]." | "Longer captions don't hurt Reels. Our test said the opposite." |
| Mid-action | start inside the moment, no setup | "...and that's when the score went to 24-24." |
| Visible stakes | show what could go wrong | "One wrong command here deletes the whole drive." |
| Specific question | a question only the target viewer cares about | "Why does WhatsApp change your photo dates?" |
| Before/after flash | show the after for 1 s, then "here's how" | |
| Direct callout | "If you [specific situation], watch this." | "If you run your college fest's Instagram, watch this." |
| Mistake reveal | "I did [X] wrong for [time]." | "I sorted 600 event photos by the wrong date." |
| Proof object | hold up / show the thing | a printed poster, a trophy, a terminal output |

Avoid: "Hey guys", "In this video", "Did you know" (overused), logo stings, any hook the video doesn't pay off.

## Second hooks (around 40-60% through)
- "But that's not the weird part."
- A new number or a reversal.
- Switch the visual style for one beat (zoom, colour change, new location).

## Endings

| Ending | Use when |
|---|---|
| Loop line | the last sentence leads naturally into the first (Shorts rewatches) |
| Specific question | goal is comments; ask something with a short, real answer |
| Save prompt | list or reference content ("save this for your next edit") |
| Send prompt | "send this to the friend who [specific behaviour]" |
| Part 2 tease | only if part 2 actually exists or is scheduled |
