# Fill-in templates

## 30 s Short script
```
HOOK (0-2s)     spoken: ______________________   on screen: ______ (<=6 words)
SETUP (2-8s)    the situation / problem in one line: __________
BEAT 1 (8-15s)  ________   visual: ________
BEAT 2 (15-22s) ________   visual: ________   (second hook here)
PAYOFF (22-28s) ________   visual: strongest proof
END (28-30s)    loop line / question: ________
Description: ________   Hashtags (1-3): ________   Disclosure needed: yes / no
```
