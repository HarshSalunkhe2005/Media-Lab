# 2. Package before you produce

The packaging is the promise. Write it first, then make the piece keep that promise.

For every piece, write three to five options of each, then pick:

| Platform | Packaging parts |
|---|---|
| Shorts / Reels / TikTok | first spoken line, first on-screen text (max ~6 words), cover frame, title (Shorts) |
| Carousel | slide 1 headline, slide 2 second hook, caption first line |
| LinkedIn / X | first two lines (everything before "see more"), document cover if any |
| YouTube long | title + thumbnail as one idea; the thumbnail shows what the title does not say |
| Event poster / story | headline, the one number or name that matters, date |

Rules:
- Title and thumbnail should not repeat each other word for word.
- Concrete beats clever: a number, a name, a visible result.
- Never promise what the piece does not deliver. Clickbait raises clicks and kills retention.
- Read it at phone size. A thumbnail must work at about 160 px wide; a cover must survive the UI overlays (see `formats/specs.md`).
